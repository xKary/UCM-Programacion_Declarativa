# UCM-Programacion_Declarativa
## Tema 1
Aprender las características básicas de la programación funcional secuencial (i.e., no concurrente) utilizando Elixir:

Definiciones recursivas y recursión de cola.
Estructuras de datos inmutables: tuplas y listas
Funciones de orden superior
Gestión de errores mediante tipos unión
Evaluación perezosa y streams
